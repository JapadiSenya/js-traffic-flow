# JsTrafficFlow

ブラウザ上で動作する交通シミュレーターです。エディタで道路網と信号を設計し、車両の初期配置・流入条件を設定した上でシミュレーションを実行、俯瞰(トップダウン)視点でCanvas上に交通の流れを描画します。任意の経路を選択して時空間図(トラジェクトリダイアグラム)を出力し、渋滞の衝撃波(shockwave)などを観察できます。

GitHub Pagesでホスティングされる静的サイトです。

## 特徴

- 道路網エディタ(ノード・車線・ベジェ曲線・信号フェーズ・スポーン設定)
- IDM(追従モデル)・MOBIL(車線変更モデル)によるシミュレーションエンジン
- 固定時間制御による多フェーズ信号(右左折矢印対応)
- Canvas 2Dによる俯瞰描画(ズーム/パン対応)
- 時空間図(トラジェクトリダイアグラム)による渋滞の可視化
- 道路網ファイル・設定ファイルの独立したexport/import(JSON)

## 使い方

ビルドステップは不要です。`index.html` をブラウザで直接開くか、任意の静的サーバーで配信してください。

```bash
# 例: 簡易サーバーで確認する場合
npx serve .
```

## 技術スタック

- Vanilla JavaScript(ES Modules、バンドラー・トランスパイラなし)
- HTML / CSS
- Canvas 2D API

## ディレクトリ構成

```
js-traffic-flow/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── editor/      # 道路網エディタ
│   ├── engine/      # シミュレーションエンジン(IDM, MOBIL, 信号制御, ルーティング)
│   ├── renderer/    # Canvas描画(道路網・車両・信号、ズーム/パン)
│   ├── ui/          # 再生コントロール、各種設定UI
│   ├── diagram/     # 時空間図の記録・描画
│   ├── model/       # 共通データモデル
│   └── io/          # JSONのexport/import
└── data/
    └── samples/     # サンプルの道路網/設定JSON
```

詳細な仕様は開発リポジトリ内のドキュメントを参照してください。
